# ☀️ Morning Digest — read less chat, know everything

A tiny local agent that reads your group chats overnight and hands you a short
Arabic morning digest: a two-line headline, the key topics, and any decisions
or action items — so you can be gloriously lazy and still miss nothing.

Built for the **Hacktoberfest Open-Source AI Challenge — Week 3: "Slow and
Steady"** (build something with open-weight models that rewards laziness 🦥).

It runs **100% locally** with **Gemma 3** via **Ollama**. Your chats are
private — they should never have to visit a cloud API just to be summarized.

## How it works

1. Export a chat from **Telegram Desktop** (`Settings → Advanced → Export
   Telegram data`, JSON format) — or use any plain-text chat log.
2. Run the digest on the export. It takes the last N hours of messages
   (default 12 — last night), anchored at the latest message in the file.
3. Long inputs are **chunked**: each chunk is summarized first, then the chunk
   summaries are combined into the final digest.
4. The digest is printed and saved to `digest-YYYY-MM-DD.md`.

## Quick start

```bash
# 1. Install Ollama (https://ollama.com) and pull Gemma 3
ollama pull gemma3        # full model; gemma3:1b works too for a quick test
ollama serve              # if the server isn't already running

# 2. Install the only dependency
pip install -r requirements.txt

# 3. Run it on the included synthetic sample
python3 digest.py sample/result.json
```

Sample output (really generated by Gemma 3 running locally via Ollama — the
`gemma3` 4B model) lives in [`sample_output.md`](sample_output.md); a faster
`gemma3:1b` run of the same sample is kept alongside it as
`sample_output_gemma3-1b.md` for comparison.

## Usage

```
python3 digest.py <result.json | chat.txt> [options]

--hours N            Recent window in hours (default: 12)
--provider ollama    Local Ollama + Gemma 3 (default)
--provider openai    Optional hosted OpenAI API (needs OPENAI_API_KEY)
--model NAME         Override the model (default: OLLAMA_MODEL env or gemma3)
--out FILE           Output path (default: digest-YYYY-MM-DD.md)
```

Configuration lives in `.env` (see `.env.example`) — following the same
provider pattern as the
[AI Post Generator](https://github.com/waleedshamhan2050-sys) project:
Ollama by default, OpenAI optional, model chosen from the environment.

## Tests (no model needed)

```bash
python3 tests/test_parse.py
```

Asserts the Telegram-export parser filters messages by the time window,
flattens text entities, and drops service/empty messages — plus the
plain-text log parser.

## Why local?

- **Privacy:** chat exports never leave your machine.
- **Offline:** it works on a laptop in Yemen with the internet down.
- **Free forever:** set it up once, never pay per summary.
- **Yours:** swap the model any time (`OLLAMA_MODEL=qwen2.5`) — no vendor lock-in.

**ملخّص الصباح** — وكيل محلي صغير يقرأ محادثات مجموعاتك أثناء الليل، ويعطيك
في الصباح ملخصاً عربياً قصيراً: عنوان رئيسي من سطرين، أهم المواضيع، وأي
قرارات أو مهام اتُّفق عليها.

يعمل **محلياً بالكامل** بنموذج **Gemma 3** المفتوح الأوزان عبر **Ollama** —
محادثاتك الخاصة لا تغادر جهازك أبداً، ويعمل بدون إنترنت وبدون أي مفتاح API.

```bash
ollama pull gemma3
python3 digest.py result.json        # آخر 12 ساعة افتراضياً
python3 digest.py chat.txt --hours 24
```

الناتج يُطبع على الشاشة ويُحفظ في ملف `digest-YYYY-MM-DD.md`. للاختبار بدون
نموذج: `python3 tests/test_parse.py`.
